# Contributing

## Issues

Issues are very welcome. If something breaks, or works differently than you expect, please
open one. It helps a lot if you include:

- the output of `phast cli version`
- the command you ran
- what happened, and what you expected
- your `composer.json` or `phast.toml`

If you found a security problem, please don't open an issue. See [SECURITY.md](SECURITY.md).

## Pull requests

Pull requests are not accepted yet. Phast is still early and changes a lot.
If you found a bug, an issue is just as helpful, and I'll credit you when it's fixed.

This will of course be revisited once Phast becomes more mature and stable.
